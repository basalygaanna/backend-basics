# City Summary

CLI-утилита: получает погоду и курс валюты к рублю из внешних API и печатает сводку.

## Требования

- Python 3.12
- Зависимости: `requests`

## Установка зависимостей

```commandline
pip install -r requirements.txt 
```

## Запуск

Например:

```commandline
python main.py --city Moscow
python main.py --city Moscow --currency EUR
```
- Аргумент --city обязательный
- Аргумент --currency необязательный

## Коды выхода

| Код | Значение |
|---|---|
| `0` | Успех |
| `2` | Ошибка аргументов |
| `3` | Город или код валюты не найден |
| `4` | Внешний сервис недоступен после retry |

## Пример вывода

```text
Город: Moscow
Погода: -3.2°C, Clear sky
Тёплая одежда: да
Нужен зонт: нет
USD->RUB: 92.15
Дорогой курс: нет
```

## Особенности:

- Логирование с run_id
- Кэш курса на 5 минут
- Типизация и флаг --json
