# Саморевью

Проверка контракта `openapi.yaml` по финальному чеклисту из лекции.

## Ресурсы и URL

| Критерий                                               | Статус |
|--------------------------------------------------------|---|
| Path: существительные, множественное число, kebab-case | ✅ | 
| Нет глагольных URL                                     | ✅ |
| id конкретного ресурса в path, фильтры - в query       | ✅ |
| Версия API указана в servers                           | ✅ |

## Методы и коды

| Критерий                                      | Статус |
|-----------------------------------------------|---|
| POST создания возвращает 201 + Location       | ✅ |
| DELETE возвращает 204 без тела                | ✅ |
| Пустой список - 200 + пустой data, не 404     | ✅ |
| Бизнес-конфликт - 409, ошибка валидации - 422 | ✅ |

## Ошибки и списки

| Критерий | Статус |
|---|---|
| Все ошибки используют один `ErrorResponse` | ✅ |
| Для 422 есть example с details | ✅ |
| На коллекциях есть фильтры, сортировка и пагинация | ✅ |
| limit имеет default и maximum | ✅ |
| `GET /loans?status=overdue` | ✅ |

## Документация

| Критерий                                    | Статус                    | 
|---------------------------------------------|---------------------------|
| Operations имеют summary, description, tags | ✅                         |
| Есть examples успеха, типичной ошибки       | ✅                         |
| Общие схемы подключены через $ref           | ✅                         | 
| Файл OpenAPI валидируется без ошибок        | ✅ (проверено через prism) |

## Схемы запросов и ответов

| Критерий | Статус |
|---|---|
| Request и response разделены | ✅ |
| Серверные поля только в response | ✅ |
| Неизвестные request-поля запрещены | ✅ |
| required, enum, nullable описаны | ✅ |

## Бизнес-правила

| Критерий                                                           | Статус |
|--------------------------------------------------------------------|---|
| выдача при available_copies > 0                                    | ✅ |
| не более 5 активных выдач на читателя                              | ✅ |
| возврат через POST /loans/{id}/return                              | ✅ |
| Просроченные: GET /loans?status=overdue                            | ✅ |
| нельзя удалить книгу, читателя с активными выдачами                | ✅ |
| due_date позже текущей                                             | ✅ |
| available_copies считает сервер                                    | ✅ |
